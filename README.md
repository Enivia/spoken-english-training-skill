# Spoken English Training Skill

一个英语口语训练 Skill。它会把学习者的真实经历转化为一套可重复的练习循环：**先尝试表达，再获得反馈，随后回忆复述，最后迁移到新的对话场景**。

它不以堆积高级词汇为目标，而是优先训练那些在真实交流中能够自然、快速说出来的英语。

## 适合哪些练习

- 每日约 10 分钟的英语口语训练
- 修改英语日记或口语表达
- 把生硬的英文改得更自然、更口语化
- 学习同一意思的不同日常表达
- 进行同学、同事、咖啡店、聚会等场景的小对话
- 在保持口语自然度的前提下提升表达的准确性、层次与语域
- 没有话题或不知道怎么开口时，获得循序渐进的提示

## 核心训练方法

一次完整训练通常包含以下步骤：

1. **先说出来**：学习者先尝试用英语表达，Skill 不会一开始就直接给出完整答案。
2. **分层反馈**：优先处理影响理解的问题、常见语法或搭配问题，以及不自然的口语表达；每轮最多聚焦三个高价值调整。
3. **主动修正**：学习者根据提示再说一次，然后才会看到完整、自然的参考版本。
4. **回忆与迁移**：通过脱稿复述、换一种说法、改变细节或回答追问，再次调用刚学到的表达。
5. **简短收尾**：总结一个值得保留的句型、一个需要记住的修正和一个可复用的口语块。

当学习者卡住时，Skill 会逐级提供帮助：

```text
尝试一个短句
→ 提供 2～4 个关键词或口语块
→ 提供填空句型
→ 必要时给出完整示范
```

## 使用示例

可以直接提出自然语言请求，例如：

```text
用 spoken-english-training-skill 带我做今天的口语练习。
```

```text
这是我今天的英语日记，请帮我改得更自然，并让我练习复述：
Today I was very tired because I had many works to do...
```

```text
模拟我第一次参加公司聚会时和同事闲聊，一次只进行一轮对话。
```

```text
我想表达“虽然结果不好，但这次经历让我更有信心”，请先让我自己尝试，不要直接给答案。
```

```text
把这段话提升得更有层次，但仍然要像日常口语，不要写成作文腔。
```

默认情况下，Skill 会根据学习者的输入推断英语水平和讲解语言。你也可以明确要求“全英文练习”“立即纠错”“练习 15 分钟”或指定具体场景。

## 反馈方式

Skill 会区分不同性质的建议，避免把个人风格偏好误判为错误：

| 标记             | 含义                                     |
| ---------------- | ---------------------------------------- |
| `❌ Error`        | 语法错误或会改变原意的问题               |
| `△ More natural` | 能理解，但日常表达中不够自然或语域不合适 |
| `↔ Alternative`  | 同样常见的另一种说法，并非纠错           |
| `✓ Strong`       | 值得保留和复用的表达                     |

反馈会尽量保留学习者原本的事实、态度和表达难度，并优先提供可迁移到其他话题的短语与句型。

## 难度进阶

训练分为三个阶段，并根据学习者无需提示时的实际表现动态调整：

| 阶段              | 训练重点         | 典型目标                                             |
| ----------------- | ---------------- | ---------------------------------------------------- |
| Say it            | 提取与修正       | 围绕真实经历说出 3～5 个连贯句子                     |
| Keep it going     | 互动与迁移       | 持续完成至少五轮闲聊，并能追问或换一种说法           |
| Shape the message | 组织、细节与语域 | 更准确地表达对比、态度、假设，并根据交流对象调整措辞 |

每次只增加一个适度挑战，例如流利度、准确性、表达范围、互动能力或语域，其余部分保持熟悉和可调用。

## 设计原则

- 先让学习者主动检索语言，再提供完整示范。
- 每轮只解决少量高价值问题，避免反馈过载。
- 纠错服务于真实交流，不为了展示复杂语法而增加复杂度。
- 保留学习者的原意、个性和大致水平。
- 把新表达带入相邻场景，训练真正可调用的口语能力。
- 只有在存在持久化记录时，才声称保存了学习历史。

## 自定义

如需调整训练方式，可直接编辑 [`SKILL.md`](SKILL.md)；更细粒度的纠错、进阶与场景规则位于 [`references`](references/) 目录。修改时建议保持核心循环完整，并让每轮教练回复足够简短，把主要表达机会留给学习者。
